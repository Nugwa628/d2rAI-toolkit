# Code of Conduct

d2rAI-toolkit is a hobby project for modders. Keep it friendly.

- **Be kind and patient.** People here range from first-time modders to reverse engineers.
- **Critique work, not people.** Say what's wrong and, if you can, how to fix it.
- **No harassment.** No insults, slurs, personal attacks, sexual content or unwanted attention.
- **Respect privacy.** Don't post anyone's personal information. That includes names or paths left in logs.
- **Respect other modders.** Don't post other people's mods, assets or code without their permission.

Maintainers may edit or remove content, and may block anyone who breaks these rules. To report a problem
privately, use the repository's **Security** tab → **Report a vulnerability** and start the title with
"Conduct:". Reports are kept confidential.

This code applies in the repository's issues, pull requests and discussions.
